Linux 上推荐官方安装器，一条命令，不用克隆仓库。有 TTY 时交互问模式；也可以把参数直接传进去。

```bash
curl -fsSL https://raw.githubusercontent.com/SnowLuma/SnowLuma.Docker.Framework/main/install.sh | bash
```

```bash
curl -fsSL https://raw.githubusercontent.com/SnowLuma/SnowLuma.Docker.Framework/main/install.sh | bash -s -- --mode docker --yes
curl -fsSL https://raw.githubusercontent.com/SnowLuma/SnowLuma.Docker.Framework/main/install.sh | bash -s -- --mode compose --network maim_bot --yes
curl -fsSL https://raw.githubusercontent.com/SnowLuma/SnowLuma.Docker.Framework/main/install.sh | bash -s -- --dry-run --mode docker
```

国内打不开 `raw.githubusercontent.com` 时，把 URL 换成 `https://ghfast.top/https://raw.githubusercontent.com/SnowLuma/SnowLuma.Docker.Framework/main/install.sh`。脚本本体在 [`SnowLuma.Docker.Framework`](https://github.com/SnowLuma/SnowLuma.Docker.Framework)。

## 三种模式

| 模式 | 做什么 | 给谁 |
| --- | --- | --- |
| `docker` | 官方镜像 + 我们的 compose，自带 QQ | 空 VPS |
| `compose` | sidecar，加入已有 docker 网络，**不改** MaiBot/AstrBot 的文件 | 已经有机器人栈 |
| `host` | 本机装 QQ + SnowLuma，不用 Docker | 进阶 / **非官方** |

没有「联合 compose」。不会替你拉起 MaiBot 或 AstrBot。

## 安装器会处理什么

- 认 Ubuntu/Debian、Fedora/RHEL/Rocky、OpenCloudOS/openEuler、Arch
- 内存、磁盘、端口占用、`ptrace_scope`
- 国内源装 Docker CE；**1Panel / 宝塔不重装 Docker、不改 daemon.json**
- 拉镜像失败会换前缀重试（直连 → 1ms → 轩辕 → DaoCloud）
- 远程桌面密码首次随机生成，写进数据卷，日志里只打一次
- 默认发布 `6081`（noVNC），**不**默认映射 raw VNC `5900`

## 装完

浏览器打开 `http://<IP>:6081/` 扫码；WebUI 在 `http://<IP>:5099/`。

```bash
docker logs snowluma 2>&1 | grep -E "远程桌面密码:|remote desktop password:|临时密码|initial credentials" | tail -n 8
```

完整端口、卷、多开说明见 [Docker 部署](/docs/guide/deploy/docker)。
