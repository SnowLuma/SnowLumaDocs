> [!WARNING]
> This is an **Alpha** script, **not** the recommended Linux path. Prefer [Docker deployment](/docs/guide/deploy/docker) for real use. The script will change; please try it if you can, and fall back to Docker if it breaks.

One command, no clone. With a TTY it asks for a mode; you can also pass flags.

```bash
curl -fsSL https://raw.githubusercontent.com/SnowLuma/SnowLuma.Docker.Framework/main/install.sh | bash
```

```bash
curl -fsSL https://raw.githubusercontent.com/SnowLuma/SnowLuma.Docker.Framework/main/install.sh | bash -s -- --mode docker --yes
curl -fsSL https://raw.githubusercontent.com/SnowLuma/SnowLuma.Docker.Framework/main/install.sh | bash -s -- --mode compose --network maim_bot --yes
curl -fsSL https://raw.githubusercontent.com/SnowLuma/SnowLuma.Docker.Framework/main/install.sh | bash -s -- --dry-run --mode docker
```

If `raw.githubusercontent.com` is blocked, swap the URL for `https://ghfast.top/https://raw.githubusercontent.com/SnowLuma/SnowLuma.Docker.Framework/main/install.sh`. The script lives in [`SnowLuma.Docker.Framework`](https://github.com/SnowLuma/SnowLuma.Docker.Framework).

## Modes

| Mode | What it does | Who it is for |
| --- | --- | --- |
| `docker` | Official image + our compose, QQ bundled | Empty VPS |
| `compose` | Sidecar joining an existing Docker network; **does not edit** MaiBot/AstrBot files | You already have a bot stack |
| `host` | Install QQ + SnowLuma on the host, no Docker | Advanced / **unofficial** |

There is no joint compose file. The installer will not start MaiBot or AstrBot for you.

## What it handles

- Ubuntu/Debian, Fedora/RHEL/Rocky, OpenCloudOS/openEuler, Arch
- RAM, disk, busy ports, `ptrace_scope`
- China-reachable Docker CE mirrors; **never reinstalls Docker or rewrites `daemon.json` on 1Panel/Baota**
- Image pull fallbacks if Docker Hub is blocked
- No shared default remote-desktop password: if you leave it unset, the first start generates a random one, keeps it on the volume, and prints it once
- Publishes `6081` (browser remote desktop) by default; does **not** publish raw VNC `5900`

## After install

Open `http://<IP>:6081/` to scan the QR code. WebUI is `http://<IP>:5099/`.

```bash
docker logs snowluma 2>&1 | grep -E "远程桌面密码:|remote desktop password:|临时密码|initial credentials" | tail -n 8
```

Full ports, volumes, and multi-account notes: [Docker deployment](/docs/guide/deploy/docker).
